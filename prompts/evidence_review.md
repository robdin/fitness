# Independent evidence review task

Input: exact script/visual text, source records, accessible source passages and claim ledger. Read the claims themselves rather than accepting the draft author's confidence.

For each claim, identify source support, population/comparison/outcome/time, uncertainty, contradictory evidence and misleading implied visuals. Distinguish acute from longitudinal results, nondetection from equivalence, and missing harms reporting from demonstrated safety. Count evidence by outcome. Flag inaccessible decisive evidence.

Output: claim_id, supported_wording, defect_severity, source_location, required_change, remaining_uncertainty. A model review proposes findings; it does not impersonate an accountable qualified reviewer or set human approval fields.
