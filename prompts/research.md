# Research task

Input: exact question, audience/decision, current source/claim ledger, date and access constraints.

Retrieve original records, verify identifiers, distinguish full text from abstract, deduplicate the same study/preprint, and document retractions/corrections when checked. Separate population, comparison, outcome and time horizon. Quote only short necessary source locations and retain links; never invent inaccessible methods or findings. Treat forum language as qualitative problem evidence.

Output JSON: question, search_log, sources, studies, supported_claims, conflicting_evidence, access_gaps, limitations, proposed_decision. Existing claims remain pending until actual review. No file deletion, paid media, publication or personal outreach is part of this task.
