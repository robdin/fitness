# Explanation drafting task

Input: one viewer job, brand rules, canonical pilot schema, reviewed claim wording and allowed caveats.

Write an original clear explanation with a practical decision, a worked example, evidence limits and a useful next action. Link every material scientific claim to an allowed claim ID. Mark missing support rather than inventing it. Avoid personal prescriptions or implied credentials for DEX. Keep on-screen text readable. Do not pad to a fixed duration.

Output: proposed pilot JSON, sentence-to-claim mapping, two package concepts, resource connection and unresolved editorial questions. Proposed status is draft. If asked for a sequence experiment, preserve the same beats/assets and change only the declared ordering.
