## Tools to add only when a need is observed

- n8n or another integration coordinator: after several real external workflows require durable scheduling. Keep one state authority.
- Managed Postgres: when multiple writers, hosting and recovery needs exceed the local store.
- Object storage with versioning: before important original production media depends on one machine.
- Word-level transcription/alignment: when caption correction time is measured and the output can be reviewed.
- A trace/evaluation platform: when local run logs no longer expose costly model errors.
- Product analytics: when actual product use needs cohort analysis beyond minimal events.

These are capability categories, not purchased services or a current best-vendor ranking. A renderer migration or extra agent framework should address a measured bottleneck.

## Fixed-budget provider benchmark

Use the same brief for a neutral character pose, expressive pose, context scene, object-only asset, difficult consistency case and short transition. Exact scientific plots and anatomy stay controlled. Record requested output, accepted output, attempts, total charged cost, reviewer time, repair time, consistency and rights/export evidence.

Score cost per accepted usable asset, not per request. Reserve the whole permitted attempt budget and share concurrency across all workers using the account. Keep prototype defaults at zero external spend until there is an actual authorized budget.
