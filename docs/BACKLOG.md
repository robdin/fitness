# Execution backlog and gates

Relative phases depend on the founder's available time; no launch date or weekly capacity has been supplied. Research passes A–F are documented. Field validation proceeds in this order.

| Priority / ID | Work | Owner | Acceptance |
| --- | --- | --- | --- |
| Now B01 | Review three topics and six sequences | Founder/editor | Concrete script/positioning notes; no format winner assumed |
| Now B02 | Set capacity, loss ceiling, scope and audience | Founder | config/business.json reflects actual decisions |
| Now B03 | Restore repository authentication | Repository owner | Fitness branch delivered; Turuan source readable |
| Now B04 | Review claims and source scope | Appropriate fitness reviewer | Approved wording, source locations and caveats per claim |
| Next B05 | Record 18 reusable beats | Narrator/producer | Current source audio retained; A/B durations match within each topic |
| Next B06 | Review six narrated versions and correct captions | Editor | No unresolved material error; exact stimuli retained |
| Next B07 | Calibrate instrument and finalize study information | Research owner | Clear items, eligibility, consent and response handling |
| Next B08 | Run exploratory six-cell screening | Research owner | Fixed horizon, unique people, exposure/missingness recorded |
| Next B09 | Inspect Turuan source and compatibility | Engineer | Guide claims checked; retained legacy fixture before any port |
| Next B10 | Conduct customer interviews and resource trials | Founder/researcher | Recent behavior, counterexamples and actual use recorded |
| Launch B11 | Prepare channel and one free-resource funnel | Founder/operator | Intended account, reviewed upload package, delivery/unsubscribe test |
| Launch B12 | Release selected pilot and run eligible packaging test | Editor | Actual remote receipt and retained native test result |
| Launch B13 | Review full production time and acquisition windows | Operator/analyst | Cash, touch time, rework and valid denominators |
| Paid B14 | Build and deliver scoped one-time paid pilot | Product owner | Concrete product, checkout/access/refund tests, actual payments |
| Paid B15 | Observe activation and repeat use | Product owner | Useful output, support costs, reasons for continued use |
| Later B16 | Decide whether to offer a recurring service | Founder | Real continuing job and sustainable delivery; clear cancellation |
| Later B17 | Integrate paid creative provider | Engineer/producer | Approved budget, receipts, uncertain-job reconciliation and retained media |
| Later B18 | Deploy durable publishing/billing workers | Engineer | Identity, scopes, retries, reconciliation, backups and restore test |
| Expansion B19 | Start another content domain | Founder/domain reviewer | First-brand economics and second-domain competency established |

The paid and expansion phases can be rejected without invalidating the educational channel. Do not increase inventory just because automation can produce more scripts.
