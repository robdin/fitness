# W14 — Workflow and agent architecture

Research round D · 20 September 2026 · Desk pass completed; operating validation pending.

## Decision

Use deterministic transitions and bounded AI-assisted tasks.

## Evidence and interpretation

Local Python commands now handle validation, manifests, rendering, assignments and accounting. Research, drafting, critique, production and analysis have separate prompt contracts. Parallel media work shares one provider budget; mutable state uses transactions.

Sources: [T03: Building effective agents](https://www.anthropic.com/engineering/building-effective-agents); [T10: Claude Code subagents](https://code.claude.com/docs/en/sub-agents)

## Alternatives

Single operator with CLI; bounded specialist roles; autonomous coordinator later.

## Experiment and decision gate

Run concurrent reservation attempts and stale-input scenarios. Do not accept natural-language claims that a render or upload succeeded without artifacts and receipts.

## Ownership and limits

Owner: Engineer. Still needed: Real provider integration and authenticated turuan reuse.
