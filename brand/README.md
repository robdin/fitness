## Discovery and distribution

Use titles that name the viewer's actual question, a clear answer near the opening, and matching captions/descriptions. Create useful answer pages with accurate authorship and primary citations where scientific claims are made. Do not keyword-stuff the channel name or present AEO as a guaranteed ranking mechanism.

Draft vertical stories as standalone explanations with their own opening, useful example and conclusion. Recompose graphics for portrait; retain the source claim's uncertainty and applicability. Record Shorts and Reels results separately because distributions and metric definitions differ. Test packaging independently from character presence and topic selection.

The [Blender MVP](../examples/blender-mvp/README.md) is one creative sample, not evidence of a winning format. It uses the P01 session audit premise and no unapproved exercise outcome claim.
