# Measurement inputs

youtube_observations.csv is an empty import template, not observed data. Map real aggregate Studio columns explicitly, retain the reporting window and timezone-aware export time, and use blanks for unavailable numeric metrics. The importer requires these exact columns and rejects an empty file as a data import.

events.json defines later funnel, cohort and commercial events. Definitions do not mean that the corresponding account integrations or events exist. Keep contact details and health data outside this repository.

For audience tests, assignments are not confirmed exposure. Keep a separate consented exposure/admin log and report nonresponse. For billing, verify current provider state before granting access; local minimal event observations are not a complete accounting ledger.
